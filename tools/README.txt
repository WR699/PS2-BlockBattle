Contenedor local de herramientas de Totrus.

install.bat crea aqui:
  tools\msys64\  - MSYS2 portable/local
  tools\ps2dev\  - PS2DEV + PS2SDK + gsKit precompilados

Las rutas de compilacion se calculan desde la carpeta del proyecto, por lo que
Totrus puede moverse a otra carpeta o unidad despues de instalar.
